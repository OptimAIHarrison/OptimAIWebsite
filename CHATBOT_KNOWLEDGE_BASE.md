## Chatbot Response Logic

### Intent Detection Algorithm

The chatbot uses keyword matching and semantic similarity to detect user intent:

```
1. Extract keywords from user message
2. Calculate similarity score against all Q&A entries
3. If confidence > 0.7, return matching answer
4. If confidence 0.4-0.7, ask clarifying question
5. If confidence < 0.4, provide general help options
```

### Clarifying Questions

When the chatbot isn't sure about intent, it asks:
- "Are you asking about [topic A] or [topic B]?"
- "Could you tell me more about what you're looking for?"
- "Are you interested in learning about our services or pricing?"

### Fallback Responses

If no match is found:

**Response 1 (First time):**
"I'm not sure I understood that correctly. Here are some things I can help with:
- Learn about our services
- Understand pricing and ROI
- Get your free audit
- Browse Ready to Go Products
- Schedule a consultation

Or, **[send a message to our team](#send-message)** and they'll get back to you within 24 hours."

**Response 2 (After 2+ unmatched questions):**
"I'm having trouble understanding your question. Let me connect you with our team who can help better.

**[Send a Message to Our Team](#send-message)** - They'll respond within 24 hours."

### Page Suggestion Logic

After each answer, the chatbot suggests relevant pages:
- **Primary suggestion:** Most directly related page
- **Secondary suggestion:** Complementary resource
- **CTA suggestion:** Action to take (audit, contact, products, etc.)

Example format:
"[Learn More About X](/page) | [View Case Studies](/case-studies) | **[Get Your Free Audit](/audit)**"

## Implementation Notes

### For Developers

1. **Knowledge Base File:** This file serves as the single source of truth for chatbot responses
2. **Keyword Matching:** Use fuzzy matching (e.g., Levenshtein distance) for better accuracy
3. **Semantic Similarity:** Consider using embeddings for more intelligent matching
4. **Page Suggestions:** Always include at least one CTA link to drive conversions
5. **Escalation:** If confidence is too low, suggest contacting the team
6. **Marketplace Links:** Include `/products` and marketplace references in service questions

### For Content Updates

When updating this knowledge base:
1. Maintain the Q&A structure (Keywords, Answer, Page Suggestions)
2. Keep answers concise (2-3 sentences max for initial response)
3. Always include relevant page suggestions
4. Include marketplace/products links in service questions
5. Test new Q&As with the chatbot before deploying
6. Track which questions users ask most to prioritize updates

### Metrics to Track

- Most common user questions
- Chatbot confidence scores
- Escalation rate to human team
- Click-through rate on page suggestions
- Conversion rate from chatbot to audit/contact/products
- Most viewed products from chatbot suggestions
